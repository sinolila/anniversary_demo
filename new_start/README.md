# Memory Meteor Shower

照片化作流星，划过记忆的星空。

## 这是什么

Memory Meteor Shower 是一个**单文件 HTML 相册应用**——你的照片会变成一颗颗流星，在星空背景中缓缓划过。
python music_downloader.py search "浪漫钢琴 lofi"     # 搜索下载
  python music_downloader.py download "YouTube链接"      # 从URL下载
  python music_downloader.py batch songs.txt            # 批量下载
  python music_downloader.py list                       # 查看已下载

  - 自动选择最佳音质（opus/aac → MP3 320kbps）
  - 下载到 music/ 目录，生成 music_manifest.json 清单

  相册音乐增强

  - 顶栏 🎵 按钮 — 上传/切换全局背景音乐
  - 预览右下 🎵 按钮 — 为当前照片指定专属歌曲（一对一映射）
  - 顶部显示当前播放曲目名称（4秒后自动淡出）
  - 胶片条缩略图显示金色音符标记 → 该照片已绑定音乐
  - 预览照片时自动切换到专属歌曲，关闭后回到全局 BGM
