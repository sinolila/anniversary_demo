# anniversary_demo

Memory Meteor Shower — 基于 HTML 的流星雨相册，支持背景音乐和动画效果。

## 项目结构

```
├── new_start/               # 主项目目录
│   ├── index.html           # 流星雨相册主页面
│   ├── music/               # 背景音乐文件
│   ├── music_downloader.py  # 音乐下载工具
│   ├── dev.sh               # 开发环境启动脚本
│   ├── setup.bat            # Windows 一键安装 (双击运行)
│   └── songs.txt            # 歌曲列表配置
├── .gitignore
└── README.md
```

## 快速开始

### Windows
双击 `new_start/setup.bat` 即可自动安装依赖并启动。

### Linux / macOS
```bash
cd new_start
bash dev.sh
```
